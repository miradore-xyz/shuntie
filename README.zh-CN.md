# 瞬贴 0.1.3

Windows 本地截图、对象标注、桌面贴图和区域录屏首版。主界面是小型深色圆角介绍窗，唯一常驻入口为设置。

## 使用

- 默认 F1 截图，F3 从剪贴板贴图，Alt+G 录屏或停止。快捷键冲突时，在设置里点击对应行，按新的组合键。
- 截图时单击选择全屏，拖动选择区域。工具栏为 Lucide 纯图标，共用背景与分组分隔线，悬停显示中文提示。
- 支持方框、箭头、画笔和马赛克。画完自动选中对象，点击已有对象即可选择并拖动；右下角控制点缩放，上方圆形手柄旋转，按住 Shift 按 15 度吸附。Delete 删除，Ctrl+Z 撤销，Ctrl+Y 重做。绘制过程中隐藏选择控制点。
- 颜色图标打开选色卡，线宽图标打开可拖动滑条。截图工具栏中的录屏图标直接录制当前选区。图标悬停 120 毫秒后显示居中的圆角中文提示。
- Enter 或复制图标复制截图；贴图图标生成带独立边框的置顶窗口。贴图可拖动、滚轮缩放、Alt+滚轮调透明度、右键关闭，按 0 恢复原始尺寸。
- 录屏显示范围边框和悬浮控制条，分别提供暂停/继续、复制 GIF、结束。暂停时点击复制，会导出暂停前的片段并写入剪贴板，之后仍可继续。暂停等待时间不进入最终视频。
- 录屏结束后保留 MP4，并后台导出 GIF。完成后主窗显示“复制 GIF”，复制完整动图文件；粘贴效果取决于目标程序是否支持文件粘贴。截图完成后保持后台运行。
- 设置页快捷键右侧的叉号用于清除绑定，清除后显示“未设置”。
- 设置中可切换 GIF 的 30/60 帧目标和开机启动。开机启动时收起到托盘。
- 设置顶部可切换中文与 English（英语），即时生效并保存选择。

## 安装与构建

安装包在 releases 中，点击“一键安装”即可完成。开机启动默认勾选，可以取消；桌面快捷方式为可选项。安装不要求管理员权限，卸载保留输出目录中的用户文件。便携运行需要保留 exe 旁的 bin 文件夹。

本机采用 Zig 0.17.0 自带 C++ 编译器，应用核心是 C++17 + Win32 / Direct2D / DirectWrite，Zig 用于构建；这不是纯 Zig 实现。使用 Windows 自带组件，主程序不需要 VC++ 运行库。执行 `./build.ps1 -Test` 构建并检查几何与命中逻辑。安装包执行 `tools/inno/ISCC.exe installer.iss` 构建。

Logo 和多尺寸图标保存在 assets 中；Lucide 原始 SVG 与许可证随项目保留。`tools/generate_assets.py` 根据这些 SVG 生成 Direct2D 绘制代码。

## 当前边界

录屏优先 DXGI 桌面复制和 NVIDIA 硬件编码；不可用时尝试兼容的软件编码。当前不录声音，录屏选区需要位于同一显示器。目标 60 帧不等于任何负载下都不掉帧。GIF 使用百分之一秒延时，编码器可合并重复帧，不保证每秒独立保存 60 张图片。导出耗时和体积取决于分辨率、内容和时长。

验证证据位于 artifacts，真实桌面冒烟检查结果位于 dist/输出/smoke-result.json。最终界面和功能验证结果见 artifacts/验收记录.txt。
