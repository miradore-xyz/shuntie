# 瞬贴 0.1.9

Windows 本地截图、对象标注、长截图、桌面贴图和区域录屏（GIF / MP4 视频）工具。主界面提供 2×2 快捷操作按钮与 5 组可配全局快捷键，右上角常驻设置入口。

## 使用

- 默认 `F1` 截图、`F3` 从剪贴板贴图、`Alt+G` 录 GIF / 停止、`Alt+L` 长截图、`Alt+V` 录视频 / 停止；也可直接在主窗口点击 **`截图 / 长截图 / 录 GIF / 录视频`**。快捷键冲突时，在设置里点击对应行按新组合键，右侧叉号可清除绑定。
- 截图时悬停预览窗口或原生面板范围，单击选中；桌面空白处单击选择全屏，拖动则自由框选。选区四角和边缘可继续拖动调整。网页内部非原生元素不在自动识别范围。
- 工具栏为 Lucide 纯图标，共用背景与分组分隔线，截图、长截图和录屏采用相同方案。
- 支持方框、箭头、画笔和马赛克。画完自动选中对象，点击已有对象即可选择并拖动；右下角控制点缩放，上方圆形手柄旋转，按住 Shift 按 15 度吸附。Delete 删除，Ctrl+Z 撤销，Ctrl+Y 重做。只有画笔落笔时隐藏选中框，松手后显示；其他工具绘制时也显示。
- 颜色图标打开选色卡，线宽图标打开可拖动滑条。截图工具栏提供长截图（`L` 键）、录 GIF 与录视频（MP4）图标，直接作用于当前选区；托盘菜单也提供对应入口。图标悬停 120 毫秒后显示居中的圆角中文提示。
- 长截图支持手动滚轮实时拼接与点击自动向下滚动（连续三次无变化自动停止），自动排除右侧滚动条并识别固定页眉/页脚，实时显示底部拼接预览；支持复制（Enter）、保存 PNG（Ctrl+S）、贴图与取消（Esc）。
- Enter 或复制图标复制截图；贴图图标生成带独立边框的置顶窗口。贴图可拖动、滚轮缩放、Alt+滚轮调透明度、右键关闭，按 0 恢复原始尺寸。
- 录屏支持 **录 GIF** 与 **录视频（MP4）** 双模式，显示范围边框和悬浮控制条，提供鼠标点击显示开关、暂停/继续、复制当前片段（GIF 或 MP4）以及结束。开启鼠标点击显示时，左键珊瑚红、右键天蓝、中键琥珀黄波纹与按住高亮环会随画面一同录制。暂停时点击复制会导出暂停前的片段并写入剪贴板，之后仍可继续；暂停等待时间不进入最终成片。
- **录视频（MP4）模式**会跳过 GIF 转换，优先保留 **原生 2K（≤2560px）** 分辨率并通过 `libx264` CRF + VBV（不支持时回退 `h264_nvenc`）压缩体积，超过 20 MB 时自动按时长与码率梯度压至 20 MB 以内（`<= 3 MB` 直接快速直通）。完成后主窗提供 **「复制视频」** 与 **「打开视频」**。
- **录 GIF 模式**同时保留并自动压缩后台 MP4，完成后主窗并排显示 **「复制 GIF」** 与 **「复制视频」**；粘贴效果取决于目标程序是否支持文件粘贴。截图完成后保持后台运行。
- 设置页支持调整 5 组快捷键、GIF 帧率（`10 / 15（默认）/ 20 / 30` fps）、GIF 画质（`2K 小体积 ≤8MB / 2K 均衡 ≤15MB（默认）/ 2K 原画 ≤25MB`）、鼠标点击显示开关、开机启动以及中英文实时切换。

## 安装与构建

安装包在 releases 中，点击“一键安装”即可完成。开机启动默认勾选，可以取消；桌面快捷方式为可选项。安装不要求管理员权限，卸载保留输出目录中的用户文件。便携运行需要保留 exe 旁的 bin 文件夹。

本机采用 Zig 0.17.0 自带 C++ 编译器，应用核心是 C++17 + Win32 / Direct2D / DirectWrite，Zig 用于构建；这不是纯 Zig 实现。使用 Windows 自带组件，主程序不需要 VC++ 运行库。执行 `./build.ps1 -Test` 构建并运行模型几何、语言切换、选区渲染、长截图拼接与视频 ≤20MB 压缩测试（`video_compress_test`）。安装包执行 `tools/inno/ISCC.exe installer.iss` 或 `./package.ps1` 构建。

Logo 和多尺寸图标保存在 assets 中；Lucide 原始 SVG 与许可证随项目保留。`tools/generate_assets.py` 根据这些 SVG 生成 Direct2D 绘制代码。

## 当前边界

录屏优先 DXGI 桌面复制和 NVIDIA 硬件编码，导出压缩优先 `libx264` CRF+VBV 以获得更高原生 2K 压缩率（必要时回退 `h264_nvenc`），输出标准 H.264 `yuv420p` MP4。当前不录声音，录屏与长截图选区需要位于同一显示器。

GIF 转换器采用单全局调色板（`GCTF=1, LCTF=0`）+ 全帧 `Disposal = 1` + 变化区域透明差分矩形 + Kornel 一维误差扩散有损 LZW，以原生 2K 分辨率起步，在兼容 QQ 群聊零拖影的前提下大幅压缩体积（超预算时优先调整有损力度、色数与帧率，尽量保留 2K 原尺寸）。每帧仍受 GIF 256 色上限限制；长截图单次拼接上限为 30,000 像素高或 256 MB 内存。

验证证据位于 artifacts，真实桌面冒烟检查结果位于 dist/输出/smoke-result.json。最终界面和功能验证结果见 artifacts/验收记录.txt。
